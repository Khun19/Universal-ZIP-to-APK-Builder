# Security Policy

## Reporting a Vulnerability

Please do not open public issues for suspected security vulnerabilities. Report them through this repository's **GitHub private vulnerability reporting** feature (“Report a vulnerability”).

Include the following where possible:
- Affected component or repository path
- Steps to reproduce the issue
- Potential security impact
- Relevant logs, artifacts, or other evidence

Reports will be reviewed and triaged. Valid reports may be handled through the repository's private security advisory workflow.

## Scope

Relevant areas include ZIP parsing and extraction, build pipeline behavior, artifact integrity and provenance, command-execution boundaries, secrets exposure, and validation or security-gate bypasses. Please provide reproducible evidence where available; findings should distinguish confirmed behavior from assumptions.
