# RZ-RELEASE — Release Approval

**Input:** RZ-GATE PASS, release class, exact pushed source commit and validated artifact. **Action:** check release evidence, identity, limitations, notes, and approval authority. **Output:** reproducible release record or explicit hold. **Evidence:** source SHA/branch, CI/tests/build, artifact hash/size/package ID/version/signing, required install/runtime evidence, known limitations, release notes, approval owner/date. **Acceptance:** all applicable release requirements are satisfied and an accountable human release owner approves; Gradle success alone is insufficient. **Owner:** human release owner. **Status:** use RZ statuses. **Failure:** missing evidence blocks release; changed source/artifact invalidates mismatched evidence and returns to the applicable gate. **Exit:** immutable released source/artifact identities and approvals are recorded; no next milestone starts without its own RZ-MILESTONE plan.
