# RZ-REVIEW — Architecture and Specification Review

**Input:** architecture, requirements, specification, risk/security notes, trace map. **Action:** check consistency, feasibility, testability, threat boundaries, regression impact, and scope. **Output:** findings with severity, owner, disposition, and approved baseline or rework request. **Evidence:** dated review record linked to exact document versions. **Acceptance:** no unresolved blocking/high-risk finding; each acceptance criterion can be tested and evidenced; security N/A has rationale. **Owner:** reviewer who did not author the reviewed material where practical; accountable human accepts residual risk. **Status:** use RZ statuses. **Failure:** return findings to RZ-DEFINE/ARCH/REQ/SPEC; do not plan implementation against rejected material. **Exit:** review disposition is approved and baseline is frozen for RZ-MILESTONE.
